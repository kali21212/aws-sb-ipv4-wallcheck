AWS.SB IPv4 WallCheck Portable V1.6
=====================================

一、这个版本是什么
----------------
这是 Windows 便携版，不需要安装 Python，不需要海外 VPS，也不需要海外基线。
它会从 aws.sb 的 EC2 实例页面自动识别 IPv4，IPv6 完全忽略，然后用当前电脑网络做：

1. ICMP Ping 主机可达性检测
2. TCP 端口检测（默认 22 / 80 / 443）
3. 每 10 分钟自动强制复检
4. 页面实例/IP变化时即时扫描
5. 同一 EC2 实例 ID 更换 IPv4 时显示“🔄 IP已变更”

重要：
因为 V1.6 按你的要求移除了海外基线，所以它只代表“当前这台电脑/当前网络是否可达”。
它不会把一次不通直接判成“被墙”，也不能单独作为绝对的 GFW 黑名单结论。

二、第一次使用
------------
1. 把整个 ZIP 解压到一个固定位置。
   例如：
   D:\Tools\AWS-SB-IPv4-WallCheck-Portable-V1.6

2. 不要直接在 ZIP 压缩包里面运行。

3. 双击：
   启动 WallCheck.cmd

4. 看到 “WallCheck started successfully.” 就表示本机探针正常。
   本机探针只监听：
   http://127.0.0.1:17654

5. 然后安装浏览器扩展（只需做一次）。

三、加载浏览器扩展
----------------
Thorium / Chrome：
  地址栏打开 chrome://extensions/

Edge：
  地址栏打开 edge://extensions/

Brave：
  地址栏打开 brave://extensions/

然后：
1. 打开“开发者模式”
2. 点击“加载已解压的扩展程序”
3. 选择本压缩包解压目录里的：
   browser-extension
4. 打开或刷新 aws.sb 的 EC2 实例页面

支持所有：
https://aws.sb/#/ec2-instances?sgt=...

不需要把某一个 sgt 值写死。

四、页面上怎么看结果
------------------
绿色：
  ✅ 主机可达｜端口可用:22
  说明主机可达，并且 22 端口当前可以连接。

绿色：
  ✅ 主机可达｜未发现开放端口
  说明 Ping 可达，但当前检测的 22/80/443 没有发现开放端口。

绿色：
  ✅ 端口可用:22｜Ping无回应
  说明主机未回应 Ping，但 22 端口能连接；主机路径仍然是通的。

橙色：
  ⚠ 本机未确认可达
  说明本次本机 ICMP/TCP 都没有获得明确可达证据。
  这不等于“被墙”，可能是目标防火墙、安全组、运营商路由、瞬时丢包等。

橙色：
  🔄 IP已变更
  表示同一个 EC2 实例 ID 的 IPv4 已发生变化。
  鼠标悬停可查看：
  旧 IP → 新 IP + 变更时间。
  标记保留 24 小时，新 IP 会立即重新检测。

五、自动检测规则
--------------
- 打开页面：立即扫描
- 页面实例/IP变化：立即扫描
- 每 10 分钟：自动强制复检
- 手动点“强制重测”：立即复检
- IPv6：完全忽略
- 同一实例换 IP：新 IP 立即检测，旧 IP 不再继续扫描
- IP 变更历史：保存在当前浏览器配置中

注意：
换到另一台电脑或另一个浏览器配置时，IP 变更历史不会自动同步。
第一次运行会把当时看到的 IP 作为基准，不会把现有 IP 全部误报为“已变更”。

六、换到其他电脑使用
------------------
直接复制整个解压后的文件夹即可。

目标电脑不需要：
- 安装 Python
- 安装 Go
- 配置海外 VPS
- 建 SSH 隧道

目标电脑只需要：
1. 双击“启动 WallCheck.cmd”
2. 在浏览器加载 browser-extension
3. 打开 aws.sb 页面

支持 Windows 10/11 x64。

七、停止 / 检查状态
-----------------
停止：
  双击 “停止 WallCheck.cmd”

检查：
  双击 “检查 WallCheck 状态.cmd”

如果显示：
  WallCheck: RUNNING
说明后台探针正常。

八、常见问题
----------
1. 页面显示“本机探针无结果”
   先双击“检查 WallCheck 状态.cmd”。
   如果没运行，再双击“启动 WallCheck.cmd”。

2. 提示 17654 端口被占用
   说明已有程序监听这个端口。
   先运行“检查 WallCheck 状态.cmd”。
   Portable 启动脚本不会自动杀掉未知程序，避免误伤。

3. 换了文件夹位置后扩展失效
   Chromium 浏览器的“加载已解压扩展”会记住原路径。
   重新到扩展管理页面加载新的 browser-extension 路径即可。

4. Windows SmartScreen / Defender 提示
   WallCheck-Agent.exe 是本地由 PyInstaller 打包的未签名 EXE，
   某些电脑首次运行可能出现 SmartScreen 提示。
   请只使用你自己保存的这个压缩包，并可用 SHA256SUMS.txt 核对文件哈希。

九、隐私与安全
------------
- 探针只监听 127.0.0.1:17654，不对局域网或公网开放。
- 浏览器扩展只把页面识别到的 IPv4 和端口列表发给本机探针。
- 不把 aws.sb 的 Cookie、账号信息、页面 URL 或 sgt 参数发送给外部服务器。
- IPv6 不会进入检测列表。
- V1.6 没有海外探针、没有海外 API、没有 SSH 隧道。

版本：
AWS.SB IPv4 WallCheck Portable V1.6.0

十、开机后的使用
--------------
本工具当前是便携模式，不写系统服务、不写注册表自启动。
Windows 重启后，再双击一次“启动 WallCheck.cmd”即可。
如果已经运行，再次启动会直接提示 WallCheck already running，不会重复启动。
